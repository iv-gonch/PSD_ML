# Запуск ноутбука

Виртуальное окружение `.venv` уже создано с доступом к установленному в системе
CERN ROOT. Из корня проекта запустите:

```bash
./start_jupyter.sh
```

В открывшемся JupyterLab выберите `gamma_n_data/view_pulses.ipynb` и выполните
`Run → Run All Cells`. Параметры канала, числа импульсов, диапазона энергии и
вычитания baseline находятся во второй ячейке.

Основной воспроизводимый CSV-пайплайн находится в корне проекта:
`csv_data_processing.ipynb`. Выберите локальный kernel `PSD_ML (.venv)` и выполните
`Run → Run All Cells`. Параметры случайной выборки, включая seed и целевой размер,
собраны в первой кодовой ячейке.

Интерактивные графики используют Plotly. Если `.venv` пересоздано, установите
зафиксированную версию перед запуском:

```bash
.venv/bin/pip install plotly==6.9.0
```

Если окружение потребуется пересоздать:

```bash
python3 -m venv --system-site-packages .venv
```
